- リンクした側は CardInstance.godLinks に入れ、バトルゾーンの一覧からは外す（覚醒リンクと同じ持ち方）。def() は withGodLinks でパワーを足し、能力・種族・文明をまとめた1枚にする（名前は「A＋B」）
- つながり方：左は中央か右に、右は中央か左に、中央は左か右に。同じ種類はひとつまで
- 離れる時：execLeave の最初で持ち主が1枚選ぶ。代表が離れる時は残りの先頭が代表になる。残りはバトルゾーンに残る
- 効果 godUnlink（「相手のゴッドのリンクを無限の数、外す」「すべてのゴッドのリンクを外す」）、条件 godLinked、キーワード extraBreak（「リンクしていれば、シールドをさらに1枚ブレイクする」）
- 画面：代表のカードに「リンク +N」の印（ツールチップにリンクしたゴッドの名前）
- 中央G・リンクの「好きな数のゴッドからカードを1枚ずつリンクを外してもよい」は入れていない（リンクするだけ）
- ブラウザで確認：ブラーがいる時にオアシスを召喚 → リンク先を聞かれる → 1体（パワー14000・3枚ブレイク・「リンク +1」）になり、その後にオアシスの出た時の能力
- 確認の罠：開発サーバーを動かしたままエンジンのファイルを書き換えると、ページに同じモジュールが2つできて、外から入れた状態でページが落ちる。サーバーを起動し直してから確かめる
- 600枚中の全自動 489 → 494、手動の行 132 → 126

## ナウ・オア・ネバーループのデッキで「手」が残る
- ユーザーのデータは GitHub Pages 版の IndexedDB（Chrome）にある。ローカルの開発サーバーやアプリ内ブラウザには何もない。
- 原因：公式が「龍聖霊ウルフェウス/ヘブンの衝撃」のように空白なしの「A/B」で名前を返すツインパクトがある。`splitTwinName` は空白つきしか分けず、両面が同じ名前のまま → `applyParsedEffects` がハイパーモードと取り違えて呪文側を消していた（呪文が唱えられず、呪文の行がクリーチャーとして読まれて手動）。
- 直し方：`splitTwinName` を空白なしでも分ける。保存済みの壊れたカード（twin なし・hyperText あり・名前が A/B）は呪文側のコストが失われていて直せないので、`isStaleOfficial` に入れて公式に届く時（起動時・ブリッジ接続時）に保存し直す。
- 「〜を1体選び、裏向きにして（持ち主の）シールドゾーンに新しいシールドとして置く」の語順も読めるようにした（ウルフェウス・エンドレーサ・ベイブレンラ）。デッキ22種すべて全自動。

## 卍月 ガ・リュザーク 卍 の手動の2行を自動に
- 「相手のターンのはじめに、相手は自身のマナゾーンのカードを3枚までしかアンタップできない」：誘発ではなく常在 `manaUntapLimit`。`parseLine` の先頭で拾わないと誘発（onTurnStart）として読まれて手動になる。アンタップするマナはプレイヤーに選ばせず、文明がばらけるように自動で選ぶ（`pickManaToUntap`）
- 呪文「次の自分のターンのはじめまで、相手は各ターン1度しか、クリーチャーで攻撃もブロックもできない」：`playLimit` の what に attack / block を足した。ブロック回数は `blocksThisTurn`（ガードマンはブロックではないので数えず、制限も受けない）
- テストの罠：manualBatch の架空カード ID（b-NN）は飛び飛びに使われていて重複しやすい。新しいものは b-901〜 にした

## 公式サイトへの接続を何もしなくても（中継サーバー）
- `relay/worker.js`（Cloudflare Workers）を追加。公式の /card/・/wp-content/card/ だけ、許可オリジンだけ、GET は10分キャッシュ
- アプリは公開版で中継を最初に使う（`relayFetcher`）。ローカルの wrangler dev で詳細取得と検索（POST）が通ることを確認
- デプロイはユーザーの Cloudflare ログインが要る（`npx wrangler login`）。デプロイ後に `DEFAULT_RELAY_URL` を書き換える
- デプロイした：https://dm-sim-relay.haixiangpingwei.workers.dev 。新しい workers.dev サブドメインは、デプロイ直後の数十秒は TLS が通らない（curl の SEC_E_ILLEGAL_MESSAGE）。少し待てば通る
