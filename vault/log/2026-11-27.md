## ナウ・オア・ネバーループのデッキで「手」が残る
- ユーザーのデータは GitHub Pages 版の IndexedDB（Chrome）にある。ローカルの開発サーバーやアプリ内ブラウザには何もない。
- 原因：公式が「龍聖霊ウルフェウス/ヘブンの衝撃」のように空白なしの「A/B」で名前を返すツインパクトがある。`splitTwinName` は空白つきしか分けず、両面が同じ名前のまま → `applyParsedEffects` がハイパーモードと取り違えて呪文側を消していた（呪文が唱えられず、呪文の行がクリーチャーとして読まれて手動）。
- 直し方：`splitTwinName` を空白なしでも分ける。保存済みの壊れたカード（twin なし・hyperText あり・名前が A/B）は呪文側のコストが失われていて直せないので、`isStaleOfficial` に入れて公式に届く時（起動時・ブリッジ接続時）に保存し直す。
- 「〜を1体選び、裏向きにして（持ち主の）シールドゾーンに新しいシールドとして置く」の語順も読めるようにした（ウルフェウス・エンドレーサ・ベイブレンラ）。デッキ22種すべて全自動。

## テキストからデッキ作成：カード名が見つからない・違うカードになるのを直した
- 原因：公式のカード名検索は**書いた文字列をそのまま含む名前**を探し、**空白は「どれかを含む」**になり、**新しい順**に並ぶ。「轟く侵略 レッドゾーン」はレッドゾーン系に埋もれ、詳細を読む上限（8件）を超えて別カードになっていた。中黒なし・全角英字・半角カナ・「=」と「＝」の違いは 0 件
- 直し方（`resolveCardName`）：語ごとに検索 → 0 件なら記号で区切った断片（NFKC）→ さらに 0 件なら前半・後半（2段まで）。当たったカードに「1/その語の件数」を足し、珍しい語を含むカードから詳細を確かめる。完全一致で止める
- 確かめた：デフォルトデッキの66枚がすべて完全一致（前は4枚が違う／見つからない）。「ロジックサークル」「ﾛｼﾞｯｸ・ｻｰｸﾙ」「ボルシャックドリームドラゴン」「CRYMAXジャオウガ」も見つかる
- 保存済みカードがツインパクトの片面一致だけの時は公式検索もして、同名の単独カードがあればそちらを先に出す
