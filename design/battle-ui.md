# 対戦画面デザイン仕様（ChatGPT 案・2026-11-26）

ChatGPT（ブラウザ版）に考えてもらった対戦画面のデザイン。実装はこの要点に沿う。

## コンセプト「DIGITAL ARCANA」
戦略を美しく魅せるデジタルカードアリーナ。深いネイビーと黒曜石を基調に、ゾーンは半透明のガラスと金属の細いフレーム。
盤面の装飾は控えめにしてカード画像を主役にし、ドラッグ・攻撃・召喚などの重要な操作でだけ発光演出を大胆に使う。
「高級感のある SF ファンタジー × 戦術シミュレーター」。既存 TCG の意匠には依存しない。

## 配色（CSS 変数）

- 枠 `--border-main #34445A` / `--border-light #53657D` / `--border-subtle rgba(143,166,194,.18)`

- アクセント 金 `#E9C46A` / シアン `#5DD9F5` / 赤 `#F45B69` / 緑 `#61D095`
- 状態 使える `#61D095` / 選択 `#F4D35E` / 対象 `#FF5A4E` / 置ける `#5DD9F5`
- 角丸 4 / 7 / 11 / 16 / 22px、パネル影 `0 8px 24px rgba(0,0,0,.35)`、カード影 `0 5px 12px rgba(0,0,0,.55)`

## レイアウト
- 盤面 : 右パネル ≒ 82 : 18（1920 幅で右パネル 344px、1366 幅で 240px）
- 盤面の縦は 相手 450fr / 中央バー 76px / 自分 554fr（1366×768 では 314fr / 62px / 392fr）
- カードの目安（1920 / 1366）：手札 88 / 64px、シールド 62 / 46px、マナ 68 / 50px、バトル 92 / 68px、山札・墓地 72 / 52px
- 右パネル：プレビュー 330px / ログ / 道具 190px

## カードの状態
使える＝緑の枠と弱いグロー、選択中＝金の二重枠で浮く、攻撃可能＝緑の脈動、タップ＝90°回転して暗く、
攻撃対象＝赤い枠と発光、封印＝グレースケールと斜線（クリックは殺さない）。優先順位はドラッグ中＞選択＞対象＞使える＞タップ・封印。

## ドラッグ
- 元のカードは薄く・少し縮める。指にはカードのコピー（-3° 傾け、影）
- 置ける場所はシアンの点線＋薄い発光、乗っている場所は実線で強く発光（scale 1.015）、置けない場所は暗く
- ラベル：マナチャージ（緑）・召喚（水色）・攻撃（赤）・シールドブレイク（金）・ダイレクトアタック（赤）・墓地へ（紫）・山札へ（青）・手札へ（白）
- 攻撃は SVG のベジェ曲線の点線矢印（クリーチャーへ赤、シールドへ金）

## アニメーション
選択 160ms ease-out / ドラッグ開始 120ms / ドロップ 280ms cubic-bezier(.22,1,.36,1) / マナチャージ 350ms cubic-bezier(.16,1,.3,1) /
召喚 500ms（1.12 倍に拡大→戻る、魔法陣）/ 攻撃矢印 350ms / シールドブレイク 450ms / ターンバナー 900ms（中央から横に展開→上へ消える）/ トースト 220ms

## 中央フェーズバー
現在のフェーズは金、終わったフェーズはシアン、未到達はグレー。次へ＝青、ターン終了＝金のボタン。

## 素材（public/battle/）
ステージ背景（16:9）、カード裏面（63:88）、ゾーンのテクスチャ（シームレス）、シールド紋章（透過）、ターンバナー（透過・横長）。
ChatGPT の画像生成で作成。文字・ロゴ・既存ゲームの意匠は入れない。
