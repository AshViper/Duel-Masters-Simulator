# アプリ全体・デッキ構築のデザイン（ChatGPT 案・2026-11-26）

ChatGPT（ブラウザ版）に考えてもらった「DIGITAL ARCANA 2.0」。対戦画面（design/battle-ui.md）と同じ配色で、アプリ全体を統一する。

## 一番の方針
- 1920×1080 と 1366×768 の両方で **ページ全体はスクロールしない**。最大幅の制限なし。
- スクロールは領域の中だけ（検索結果・カードの能力テキスト・一覧など）。
- grid の子には必ず `min-width: 0; min-height: 0`（中身に引っ張られてはみ出すのを防ぐ）。

## 共通の枠組み
- 左ナビ 64px（アイコン＋小さい文字。選択中は左端に金のライン）＋ 上部バー 48px ＋ メイン。
- パネル間隔 10px、パネル内余白 10〜12px、角丸 7〜11px、ボタン高さ 30〜36px。
- 対戦画面は枠組みを使わず全画面。

## デッキ構築
- 3列：検索 `clamp(300px, 23vw, 440px)` ／ デッキ `minmax(0, 1fr)` ／ カード詳細 `clamp(250px, 18vw, 340px)`。
- 上部バーにデッキ名（その場で編集、未保存は金の点）・枚数・操作ボタン（保存＝金、削除＝赤）。
- デッキの40枚は、空いている幅と高さからカードの大きさを計算して必ず収める。
  ChatGPT のおすすめは 10列×4段。実装では 8列×5段 と 10列×4段 のうちカードが大きくなる方を自動で選ぶ
  （縦に余裕のある画面では 8×5 の方が大きくなるため）。超次元ゾーンは別の列（最大8枚）。
- デッキの下に統計（文明の枚数・コストカーブ・手動処理・ルール違反）を横1列で常に表示。
- 右にカード詳細を常に表示（画像・名前・コスト・文明・種族・パワー・能力テキスト・追加/減らす）。
  ホバーで一時表示、クリックで選択。右クリックは拡大表示（モーダル）。
- 検索フォームは2列：名前｜テキスト、種族｜パック、文明6色、コスト｜タイプ、レアリティ｜クリア。
- 検索結果のカードは 88〜112px、右上に枚数バッジ（1〜3枚＝緑、上限＝金で追加不可）。
- 操作：結果を左クリックで追加、デッキを左クリックで1枚減らす。ドラッグ＆ドロップは補助
  （結果→デッキで追加、デッキ→検索側で1枚減らす。置ける場所はシアンの枠）。
- 追加時は 150〜200ms の短い演出（追加したカードが弾む、枚数が光る）。

## ほかの画面
- ホーム：ダッシュボード。大きめのメニュータイル＋最近のデッキ＋中断した対戦。
- デッキ一覧：代表カードの画像つきタイル（デッキ名・枚数・文明・使用可否）。最初に「新しいデッキ」のタイル。
- カード図鑑：デッキ構築と同じ3列（フィルタと管理｜カード一覧｜カード詳細）。
- 対戦開始：対戦方法・CPU の強さ・先攻（左 `clamp(290px, 24vw, 400px)`、下に金の「対戦開始」）｜自分のデッキ｜VS｜相手のデッキ。
  デッキは `DeckPicker`（選んだデッキを大きく＋デッキ一覧。自分はシアン、相手は赤）。
- オンライン：プレイヤー名とデッキ（左）｜部屋（右 `clamp(340px, 34vw, 560px)`：部屋を作る／部屋に入る、待機中は金の大きな部屋コード）。上部バーに接続状態の点。
- 設定：項目のパネル（対戦・構築ルール・データ）を左に、殿堂レギュレーション（JSON 編集｜カード名の一覧）を右に。
